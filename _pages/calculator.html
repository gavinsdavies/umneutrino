Neutrino Oscillation Calculator

Move the parameters and watch the oscillation probabilities change. Everything is computed live in your browser — nothing is sent to a server. The physics is a three-flavour PMNS calculation in constant-density matter, with optional non-standard interactions (NSI), ported from nuosclab and checked against it to better than 10−12 in probability.

Physics engine ported from nuosclab (Davies, MIT licence, 10.5281/zenodo.21919616), which mirrors OscLib's PMNS_NSI. Constants are PDG 2024. The browser engine is held to the Python reference by a golden-file test; see the repository for the validation harness. Parameter settings are stored in the page URL, so a configuration can be linked or cited.
